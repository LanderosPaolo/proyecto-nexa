# 🌿 Proyecto NEXA — Landing Page Responsive

Landing page desarrollada para **Somos NEXA Chile**, un centro de gestión interdisciplinaria enfocado en ofrecer formación, herramientas y recursos a profesionales que trabajan en contextos de vulneración de derechos.

El proyecto consistió en construir una interfaz web informativa, visualmente coherente con la identidad de la marca y adaptable a diferentes dispositivos, utilizando **HTML5, CSS3 y JavaScript**.

Esta versión corresponde al desarrollo original de la landing page, previo a la personalización posterior del sitio mediante Shopify.

## 🎯 Objetivo del proyecto

Desarrollar una presencia digital que permitiera comunicar la propuesta de valor de NEXA, presentar sus principales servicios y facilitar el acceso a sus recursos y canales de contacto.

El diseño se enfocó en una navegación sencilla, una jerarquía visual clara y una experiencia adaptable a dispositivos móviles y de escritorio.

## ✨ Características principales

- Diseño responsive para escritorio, tablet y dispositivos móviles.
- Navegación interna entre las distintas secciones.
- Presentación de cursos, capacitaciones, guías y recursos profesionales.
- Sección informativa sobre la organización y sus valores.
- Identificación del público profesional al que se dirige NEXA.
- Integración de enlaces externos hacia recursos y redes sociales.
- Sección de contacto con acceso directo al correo electrónico.
- Botón interactivo para regresar al inicio de la página.
- Animaciones y efectos visuales mediante CSS.
- Consideraciones de accesibilidad y preferencias de movimiento reducido.

## 💻 Implementación técnica

### Maquetación y diseño responsive

Construcción de la interfaz mediante HTML semántico y CSS personalizado, utilizando media queries para adaptar la distribución y presentación de los elementos según el tamaño de pantalla.

### Diseño visual

Aplicación de una identidad gráfica consistente mediante colores, tipografías, imágenes, tarjetas informativas y elementos interactivos.

### Interactividad con JavaScript

Implementación de un botón de retorno al inicio que aparece dinámicamente cuando el usuario se desplaza por la página.

### Navegación y accesibilidad

Uso de enlaces internos, descripciones para imágenes, atributos accesibles en controles y ajustes para respetar las preferencias de reducción de movimiento del usuario.

## 🚀 Ejecución local

Este proyecto utiliza HTML, CSS y JavaScript nativos, por lo que no requiere instalación de dependencias ni compilación.

**1. Clonar el repositorio**

```bash
git clone https://github.com/LanderosPaolo/proyecto-nexa.git
```

**2. Entrar al directorio**

```bash
cd proyecto-nexa
```

**3. Ejecutar**

Abrir el archivo `index.html` en un navegador web.

También puede utilizarse la extensión Live Server de Visual Studio Code para facilitar el desarrollo local.

## 🧩 Evolución del proyecto

La landing page representó una primera etapa de desarrollo de la presencia digital de NEXA.

Posteriormente, el trabajo continuó con la adaptación y personalización de su sitio en **Shopify**, considerando el diseño visual y la organización de contenidos para una plataforma orientada a la comercialización de recursos digitales.

El código de este repositorio corresponde a la implementación original en HTML, CSS y JavaScript, no al tema de Shopify.
